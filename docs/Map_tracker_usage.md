# Map Tracker Usage
### Location Accessibility
When using the Full Item Level Order Randomizer Map Tracker pack, the locations of item checks update based on the items the player has currently highlighted in the "Kongs / Abilities / Collectables / Lobbies" tracker, in tandem with the enabled settings. The color of each location represents the accessibility of the check as follows:
- Green: This item check is accessible and in logic for the player to obtain
- Yellow: This item check is accessible, but not in logic
- Blue: This item check is not accessible, but can be peeked to see what type of item the check contains
- Red: This item check is not accessible and not peekable
- Orange: This location contains multiple item checks at varying levels of accessibility
- Gray: This location has been checked off and is empty, or contains no applicable checks (such as each level's Location Shuffler hub when only DK Portals are shuffled, as the hub stores the Portal Location which itself is not a check that can be completed)

### Check Location Logic
The map tracker assumes glitchless logic to determine the logical accessibility of its map locations. Some checks may be marked yellow as out of logic if they are accessible using damage boosting, Tag Anywhere, or by utilizing the "Advanced Glitchless" tricks such as Hard Shooting or Monkey Maneuvers.

The map tracker's logic also assumes a few attributes that would be too volatile to be useful:
- Every check location requires either any of the Kongs or a specific Kong, so no locations will show up until at least 1 Kong is highlighted in the tracker
- All non-Isles level check locations and level lobby check locations will not be in logic until the appropriate level lobby is selected in the tracker and the player can access that lobby from DK Isles
- The non-Isles levels will be shown as accessible in logic as soon as the player has access to that level's lobby, regardless of whether the player has enough of the set collectable to get past the randomized B. Locker
- Each level has a "Colored Banana Reward" location hub next to its title indicating checks that can be acquired anywhere in the level through colored bananas, such as Banana Medals, Half-Medals, and the level's Boss
- Each level also has a "Location Shufflers" location hub for randomizing the locations of Kasplats, Dirt Patches, Melon Crates, Fairies, Battle Arenas, and the level entrance
- The Jetpac game check will show up in all Cranky's Lab hubs once the tracker is set to enough Banana Medals, clearing this location in any Cranky's Lab will clear it in all of them
- Bonus Barrel checks are in logic as soon as the barrel can be accessed with the Kong assigned to the barrel, without considering the potential additional requirements of the randomized minigame within
- The logic has no knowledge of Banana Coins, so shop purchases are accessible as soon as you have that Kong, that Shopkeeper, and can access the shop
- Due to randomized Troff 'n' Scoff values, the tracker also cannot determine when the player would have enough colored bananas for the Boss, and thus marks it as available as soon as the level is accessible. It also does not account for situations in which the player cannot yet access a Troff 'n Scoff portal
- If Kasplats are shuffled between their vanilla locations, they will be marked as accessible as soon as any Kong can defeat them, even if the proper Kong is not owned yet
- The two Golden Bananas involving Diddy's cage in Japes have event flags tied to them (denoted with checkmarks), corresponding to collecting the item in front of the cage (which spawns the gun switches), and collecting the item within the cage (which opens the gates to the rest of Japes)

### Capturing Items
Many item check locations are capturable using the dashed box next to the vanilla item icon. All item checks possess this capture box except checks that cannot be seen until they are immediately collectable (such as the Squawks instrument pads in Isles or Melon Crates). The capture box items contain some quirks:
- The potions can apply to many different abilities on the tracker, and thus will not update any particular ability when the location is checked
- Similarly, the generic Key item can apply to any of the 8 Keys, but due to each Key behaving differently in the logic, the captured Key will not update any particular Key on the tracker. The generic Key counter will update to reflect the total number of specific Keys collected if a new specific Key is marked
- An ice trap option is given for checks that can be visually identified as an ice trap, checking these will increment an internal ice trap counter that is otherwise not represented on the tracker (ice trap visual borrowed from Hamsda's ZOoTR Map Tracker)
- All other items on the capture menu will correctly increment or highlight their associated item on the tracker when the captured location is checked

## Settings
The tracker features a settings menu accessible by clicking the gear icon above the "Kong / Abilities / Collectables / Lobbies" tracker. These settings include the randomizer settings that impact the logic in a trackable way, and are split into 6 groups of settings: Main Logic Settings, Item Pools, Check Amount Thresholds, Location Shufflers, Open Barriers, and Switchsanity
- Each setting can be hovered over with your mouse for a brief description of what the setting is controlling. For settings which are not just off or on, the default setting is surrounded by asterics, with the other options cycling in sequence as the setting is left clicked
- Certain settings may have a sub-setting associated with them which can be toggled separately by right clicking the option. These include Advanced Grenading by right clicking Hard Shooting, Slope Resets by right clicking Monkey Maneuvers, Season 5 Melon Crate Locations by right clicking the Melon Crate Pool, and disabled Wrinkly Puzzles by right clicking Kongless Hint Doors

### Main Logic Settings
The default settings are set to general beginner friendly preset values. There are 12 available options corresponding to various toggles in the randomizer that affect location logic in some way:
- Auto Complete Bonus Barrels: represented by the Bonus Barrel icon, changes the logic of a handful of Bonus Barrels to not require certain movement to the Bonus Barrel, such as Diddy's Bonus Barrel in Snide's DK Isles Lobby no longer requiring Simian Spring. Defaults to OFF
- Open Lobbies: represented by the B. Locker icon, controls whether the lobbies expect their respective keys for logical access. Note that, if this setting is enabled, lobbies 2 and 6 will still need a way to access upper DK Isles. Defaults to OFF
- Progressive Switch Strength: represented by the Simian Slam DK Switch icon, changes behavior of locations behind Simian Slam switches such that switches in the first 4 randomized levels require Simian Slam, switches in levels 5 and 6 require Super Simian Slam, and switches in level 7 require Super Duper Simian Slam (including the Galleon lobby switch as the same Slam level as Galleon itself). Defaults to ON
- Free Trade Agreement: represented by the Tag Barrel icon, toggles logic for locations accessible without their assigned Kong unlocked yet (mostly vanilla Kasplat locations). Note that since the tracker has no knowledge of what the actual collectible will be from checks, this setting when enabled mirrors the logic of both the "Major Collectibles" and "Major Collectibles except Blueprints" options for Free Trade Agreement in the randomizer
- Factory DK Arcade GB Location: represented by the shiny Golden Banana / Gorilla Grab icon, changes location of the DK Arcade GB to the Barrel Blast course if the Shiny Golden Banana is toggled, matching the Faster Check option. Defaults to ON in Season 3 settings
- Galleon Cheap Mermaid: represented by the Mermaid icon, changes behavior of the Mermaid check in Galleon to be in logic with 1 out of 5 pearls, matching the Faster Check option. Defaults to ON
- Galleon Default Water Level: represented by the Enguarde icon, changes the logic of checks in Galleon to assume either lowered or raised water by default. Defaults to Raised
- Forest Default Time: represented by the Shroom Kremling and/or Krossbones icon, changes the logic of checks in Forest to assume either Day, Night, or both (Dusk) for various access checks. Any Progressive time setting also should set time to the Dusk setting as all times can be accessed without additional logical requirements. Defaults to Day
- Hard Shooting: represented by the Coconut Gun image, sets the Advanced Glitchless logic for not requiring Homing Ammo/Sniper Scope for some checks. Note that these locations will display as yellow if all other logical requirements are met when this setting is turned off, indicating that they can still be acquired, but it is not expected in logic. Defaults to OFF
- Advanced Grenading: right-clicking the Hard Shooting icon will activate Advanced Grenading (represented by the Orange in the lower-right corner). Enables the Advanced Glitchless logic for using oranges for some enemy trials and changing time of day in Fungi Forest. Defaults to OFF
- Chunky Phase Slam Requirement: represented by the Chunky Simian Slam Switch, sets the Simian Slam level needed to spawn the Gorilla Gone pads in Chunky Phase of the K. Rool Fight, if applicable. Defaults to (Base) Simian Slam
- Pre-Activated Bananaports: represented by the Bananaport 1 icon, toggles logic allowing access to some areas early if the Bananaports in those areas are pre-activated. Analogous with the "Activate Bananaports" setting in the randomizer, defaults to Isles Only
- Helm Start Location: represented by the top of Krem Isle icon, toggles logic expecting certain moves for checks in the Hideout Helm level hub. Analogous to the "Helm Start Location" option in the randomizer, defaults to Skip Start (icon highlighted with ½ to denote starting halfway through Helm)
- Monkey Maneuvers: represented by DK shaking his leg, sets the Advanced Glitchless logic for various unintuitive tricks to skip certain check requirements. Note that these locations will display as yellow if all other logical requirements are met when this setting is turned off, indicating that they can still be acquired, but it is not expected in logic. Defaults to OFF
- Slope Resets: right-clicking the Monkey Maneuvers icon will activate Slope Resets (represented by Lanky in Orangstand in the lower-right corner). Enables the Advanced Glitchless logic for climbing steep slopes without Lanky/Orangstand through various methods. Defaults to OFF

### Item Pools
Each item pool setting toggles the visibility of its respective vanilla check locations
- Half-Medals, Snide Rewards, Melon Crates, Holdable Objects, and Hints default to OFF, all other pools default to ON
- The Melon Crate Pool can be right-clicked to enable the set [Season 5 Melon Crate locations](https://docs.google.com/spreadsheets/d/1Nnfgn7PdlCjY-n1cs1fuxp3bRsx3S-sYk5gmVdVnLtw/edit?gid=277924991#gid=277924991) (denoted by the 5 in the bottom-right corner)

### Check Thresholds
- Half Medal Colored Banana Amount: represented by the Half-Medal, controls how many colored bananas must be collected for each Kong's Half Medal check in each level. Note this is the absolute value at which you obtain the check, not the percentage of the full medal (so Half-Medals set to 50% of 60 should set this value to 30)
- Medal Colored Banana Amount: represented by the Banana Medal, controls how many colored bananas must be collected for each Kong's Banana Medal check in each level. The map tracker internally converts the marked Kongs, Abilities, and Settings into a current total available vanilla colored banana amount per level per kong to determine the accessibility of these checks
- Jetpac Banana Medal Amount: represented by the Jetpac man, controls how many Banana Medals must be collected before the Jetpac check in all Cranky's Lab hubs becomes accessible
- Rareware Banana Fairy Amount: represented by the Banana Fairy counter, controls how many Banana Fairies must be collected before the Rareware Golden Banana check is accessible
- Mermaid Pearl Amount: represented by the Pearl counter, controls how many Pearls must be brought to the Mermaid in Gloomy Galleon to receive her check
- Helm B. Locker Amount: represented by the Golden Banana counter, controls how many Golden Bananas the Helm B. Locker requires. Meeting or exceeding the Golden Banana amount will make the Hideout Helm level hub accessible (if the player also has the necessary requirements to enter and cross Helm Lobby)
- Helm Door 1 / 2 Amount: represented by both Helm Door counters along with the collectible icon beneath them, together these control the type and amount of collectibles needed for each Helm door. Note that being able to open Helm Door 1 but not Helm Door 2 allows the player to peek the Key 8 and 2 vanilla Helm Banana Fairy item checks, but otherwise the doors are interchangable

### Location Shufflers
- Banana Fairy Location Shuffler: represented by the X'd out Fairy icon. Note that, when enabled, the Banana Fairy vanilla locations will be moved into each level's Location Shuffler hub and the 2 checks (4 in Isles) will show as peekable as soon as you have access to a level, and in logic as soon as you have the Fairy Camera
- Kasplat Location Shuffler: represented by the Kasplat icon, analogous to the "Shuffle Kasplat" options in the randomizer. "Vanilla" and "Vanilla Locations" will maintain the Kasplat location boxes in each level, "Location Shuffle" (the Kasplat with ?'s) will move all Kasplat locations into each level's Location Shuffler hub and all Kasplat rewards will show as in logic in each level as soon as you have that respective Kong
- Battle Arena Location Shuffler: represented by the Battle Arena icon. Note that, when enabled, the Battle Arena vanilla locations will be moved into each level's Location Shuffler hub and the check (2 checks in Isles) will show as in logic as soon as you have access to a level
- DK Portal Location Shuffler: represented by the DK Portal icon. When enabled, spawns an indicator in each level's Location Shuffler hub for which logical region of the level you spawn into. Note this currently only supports main map locations
- Colored Banana Location Shuffler: represented by the 5 single bananas icon. Removes the logic pertaining to vanilla colored bananas for each level's Banana Medal checks, so each Kong's Banana Medal check in a level will simply be displayed as in logic as soon as that Kong is acquired and that level is accessible
- Dirt Patch Location Shuffler: represented by the Dirt Patch icon. Note that, when enabled, the Dirt Patch vanilla locations will be removed in each level and replaced by 2 checks (4 in Isles) in each level's Location Shuffler hub. The checks will be in logic once you have the Shockwave ability, and note that while each level has 2 locations available, in practice each level will have 1 to 2 Dirt Patch locations, except Isles which will always have exactly 4
- Melon Crate Location Shuffler: represented by the Melon Crate icon. Note that, when enabled, the Melon Crate vanilla locations will be removed in each level and replaced by 2 checks in each level's Location Shuffler hub. Further note that while each level has 2 locations available, in practice each level will have 1 or 2 Melon Crate locations

### Open Barriers
This menu contains a toggle for each removable barrier, and will update the logic for locations behind that barrier accordingly
- The tracker starts with the default barriers from Season 4 opened (all barriers except Japes Shellhive Gate, Aztec Llama Switches, Galleon Lighthouse Gate, Galleon Treasure Room, Both Forest Tunnels, and Castle Crypt Doors)

### Switchsanity
This menu allows the required gun/instrument/move/etc. to be set for each switch in the Switchsanity settings. They have been broken into 9 groupings for easier tracking:
- Helm Access: These two switches control what is required to access Helm. The first icon controls how to access the top of Krem Isle (where Helm Lobby is accessed), it can be set to Monkeyport, Baboon Blast, Baboon Balloon, or Unknown; The second icon controls what makes the Vines in Helm Lobby grabbable, it can be set to Gorilla Gone, Gorilla Grab, Chimpy Charge, any Kong instrument, or Unknown
- Isles Switches: These switches can be found in Isles/the level lobbies. The first icon controls access to the door in Aztec Lobby, it can be set to any Kong gun; the second icon controls the door containing the Banana Fairy in Forest Lobby, it can be set to any Kong gun; the third icon controls the pad near Aztec Lobby which spawns the Rocketbarrel Boost Barrel outside Forest Lobby, it can be set to any Kong instrument
- Japes Hill Switches: These switches can be found in the main Japes area. The first icon controls the switches spawned by the Japes Kong puzzle, it can be set to any Kong gun; the second icon controls the switch over the Japes Painting room, it can be set to any Kong gun
- Japes Tunnel Switches: These switches can be found in Japes tunnel and stormy areas. The first icon controls the dual switches which open the door to the Shellhive area, it can be set to any Kong gun; the second icon controls the dual switches which open the door in the tunnel near the start of Japes, it can be set to any Kong gun; the third switch controls the switch over the Rambi box, it can be set to any Kong gun
- Aztec Kongs: These switches are associated with the Kong puzzles in Aztec. The first icon controls the puzzle to be solved to open the cage in Tiny Temple, it can be set to Chimpy Charge, Primate Punch, or Unknown; the second icon controls the puzzle to be solved to open the cage in Llama Temple, it can be set to any Kong's gun/instrument combo
- Aztec Llama Temple Entry: These switches allow access to the Llama Temple. They represent the switches spawned on the front, left side, and back of Llama Temple respectfully, and can each be set to any Kong gun
- Aztec Tunnel Switches: These switches are associated with barriers in Aztec tunnels. The first icon controls the dual switches which open the room with the bridge over quicksand in the first Aztec tunnel (where the yellow hair Kasplat is by default), it can be set to any Kong gun; the second icon controls the instrument necessary to open the door connecting the Oasis area to the rest of Aztec, it can be set to any Kong instrument; the third switch controls the Kong necessary to open the quicksand tunnel by using Simian Slam on the switch in Llama Temple, it can be set to any Kong
- Galleon Switches: These switches are associated with barriers in Gloomy Galleon. The first icon controls the dual switches leading to the Lighthouse Area, it can be set to any Kong gun; the second icon controls the dual switches leading to the Shipyard Area, it can be set to any Kong gun; the third switch controls the dual switches leading to the Cannon Room, it can be set to any Kong gun
- Forest Switches: These switches are associated with barriers in Fungi Forest. The first icon controls the switch above the yellow tunnel leading from the Giant Mushroom area to the Owl Tree area, it can be set to any Kong gun; the second icon controls the dual switches on the Clocktower side of the green tunnel, it can be set to any Kong gun; the third icon controls the dual switches on the Beanstalk side of the green tunnel, it can be set to any Kong gun
- Any gun or instrument switch can be set to allow any usable gun/instrument, denoted by the gun ammo icon and headphones icon respectively. All switches can be set to Unknown, which will set the switch as inaccessible until the switch is set
- All switches default to their requirements in vanilla DK64

### Endgame/Go Mode Tracker
- The "GET OUT" Text under the Helm selector will automatically illuminate when the tracker identifies that everything required to beat the game is satisfied based on your Endgame Tracker:
- If the K. Rool Barrel icon is illuminated, the tracker will check for Helm Entry requirements and completing Helm requirements to get to the Key 8 item location. If the K. Rool icon is illuminated, the tracker will check for the necessary moves for every selected Kong to defeat their Phase of the K. Rool fight
- The K. Rool Barrel icon denotes the seed's helm order. The Kongs that disable Helm should be input left to right, with any unused slots set to the Funky icon. If Key 8/An endgoal item isn't locked in Helm, the K. Rool Barrel icon itself should be right clicked to indicate it is not part of the seed's Go Mode
- The K. Rool icon denotes the seed's K. Rool order. The Kongs that fight K. Rool should be input left to right, with any unused slots set to the Funky icon. If the seed's win condition is not set to Beat K. Rool, the K. Rool icon itself should be left clicked to indicate it is not part of the seed's Go Mode
- The K. Rool icon can be right-clicked to additionally require Baboon Blast for DK's Phase of the fight, as indicated by the DK Pad in the top-right corner

## Hints
- Under the Endgame tracker is a section for setting and recording hints as given by Wrinkly in game. There are three settings (two icons) to be set at the top:
- Hint Locations: There are currently 4 options for where hint locations will show up on the map tracker: in their vanilla locations in the Isles lobbies (denoted by the Wrinkly face icon), in the Dos' Doors locations, as denoted by the Troff 'n Scoff portal (one hint in each lobby + 4 hints on 4 out of 5 vanilla Troff 'n Scoff locations in each level), in the [Season 5 set Seasonal Hint locations](https://docs.google.com/spreadsheets/d/1Nnfgn7PdlCjY-n1cs1fuxp3bRsx3S-sYk5gmVdVnLtw/edit?gid=277924991#gid=277924991) (denoted by the 5 icon), and in the level's Location Shuffler hub (denoted by the ? icon)
- Kongless Hint Doors: represented by the Diddy Wrinkly Hint door with Donkey Kong's thinking face, this makes all locations in the Hint Pool accessible as soon as any Kong can access the location. Defaults to ON
- Remove Wrinkly Puzzles: represented by a Boulder when right-clicking the Kongless Hint Door icon, this changes a few Hint Pool locations in Aztec, Forest, and Caves lobbies to align with the changes made by the "Remove Wrinkly Puzzles" option in the Misc Changes selector in the randomizer. Defaults to ON
- Each level is given 5 or 7 regions corresponding to the Hint Regions in the Randomizer. The first two regions are always set to the Colored Banana Rewards and Shops for that level respectively, and the other regions vaguely progress through the level as one would in a vanilla playthrough
- There is also a Global hub for Hint Regions not corresponding to any set level, including Starting Items, all Bosses (Troff 'n Scoff), and each set of 8 Snide Rewards
- The Hint Regions for Jetpac and the Rareware Banana are excluded as these are single locations that can be handled by their respective locations on the map itself
- The Hideout Helm region replaces the Colored Banana Reward region for Isles, except when Colored Bananas Location Shuffler is enabled
- When Hint Locations are set to Season 5 locations, the hubs for Frantic Factory Start and all Snide Rewards beyond 8 are removed, as the Season 5 settings do not have any hintable checks in these areas
- Each region can be used to capture an important item found in that region. By setting an item on the dashed capture box in a region, a small icon of that item will be placed on the bottom-left corner of that region as a reminder of where it was received
- Each region can also take more in-depth notes by utilizing EmoTracker's Edit Notes feature: by clicking the square and pencil symbol on the top right of each region, a dialogue box will open allowing the user to input notes however they see fit, and capture multiple items associated with each note
- To align with the possible given hints, the capturable items for Hint Regions include a Kong Path item (denoted by the Tag Barrel, for hints pertaining to Freeing Kongs), a Foolish item (denoted by the GET OUT icon, for regions that have been deemed foolish), and a generic Potion (for scouring hints)
